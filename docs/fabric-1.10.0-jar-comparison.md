# Fabric 1.10.0 JAR 对照与 Forge 迁移

对照根目录的 `shape-shifter-curse-fabric-1.10.0.jar` 和
`shape-shifter-curse-fabric-1.10.0_beta.jar`。两者的 `fabric.mod.json`
均标记为 1.10.0、release、ChannelVersion 0，不能仅凭内部版本字段判断先后。
以下数字按 ZIP 条目名称和 CRC 比较，代码及资源字节变化不一定代表功能变化。

- 正式包独有 40 个文件，包括旧 `alter` 资源、配方和相关类，以及部分旧技能界面资源。
- beta 包独有 300 个文件，包括 95 个能力数据、25 个配方、10 个饰品能力数据，
  以及强化饰品、催化核心、武器和调谐器界面的资源与相关代码。
- 同名但内容不同的文件有 425 个，包括 205 个类、80 个玩家动画文件、
  15 个形态模型和多种语言、配方及能力数据。这里包含格式或构建差异，需逐项核实。
- beta 包元数据增加了 CC-BY-SA-2.0 许可标记；使用新增资源时应逐项核实其许可和归属。

## Forge 迁移进度

Forge 已注册 `altar` 和 `form_attuner` 方块及物品，本次补充 beta 的对应掉落表。
破坏时按照爆炸生存条件掉落对应方块物品。
已加入 beta 的祭坛工作台配方，并修复 Forge 祭坛无序配方对重叠材料的匹配及重复材料的扣除。
已将燃料槽与催化剂槽分开，按 beta 的每 tick `fuel_cost` 或总量 `moondust_cost`
消耗月尘；旧版祭坛输出槽在加载旧存档时迁移。已接入调谐器、涟漪镜和月尘水晶碎片
的 beta 祭坛配方。催化剂作为可重复使用的配方条件。

已补充 beta 独有物品的注册、创造栏、物品模型贴图、名称、Curios 槽位和
21 条新增祭坛配方，以及新增的能力、饰品数据、界面资源和标签。新增资源附有
Fabric 包中的原始许可和署名文件。强化饰品及技能相关能力仍需逐项验证，不能
仅凭能力数据文件存在就认为所有效果已实现；三个药剂符纸的投射物行为仍未迁移。

其余内容尚未完成对照：技能树、强化饰品的具体能力、调谐器界面，以及同名代码、
动画和模型的行为变化均需进一步迁移和测试。
Fabric 的 Apoli 能力定义和配方不能直接视为 Forge 端已实现；应结合 Forge
的注册、能力系统及实际资源加载逐项核查。
